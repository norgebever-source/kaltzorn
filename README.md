# Kaltzorn

Offizielle Künstlerseite für [Kaltzorn](https://suno.com/@kaltzorn).

- Vorschau: https://norgebever-source.github.io/kaltzorn/
- Eigene Domain `kaltzorn.de` ist geplant (DNS bei IONOS). Dafür später eine Datei `CNAME` mit dem Inhalt `kaltzorn.de` ins Repository legen und die DNS-Einträge auf GitHub Pages zeigen.

Die Seite ist statisch (HTML/CSS), ohne Tracking und ohne externe Schriftarten.
